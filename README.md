# 我們的小島 · Our Little Island

以《卡坦島》啟發的實體策略桌遊美術呈現家族互動網站：加厚木邊六角地塊、程序繪製的森林／麥田／牧場／山地／紅土地表、木製聚落與道路、數字圓牌與海洋棋盤。所有地形紋理和模型均以程式自行繪製，沒有使用原桌遊素材。以 Three.js 建立六角形 3D 群島。每座原有島嶼的土地面積擴大為初版的 5.76 倍，中央新增河畔公園、草坡、涼亭與跨河木橋。外圍海洋棋盤半徑加寬約 50%。拖曳旋轉、右鍵平移、滾輪縮放；也可切換「移動地圖」，用左鍵或單指平移，觸控裝置可雙指縮放與平移。最高可放大至 8 倍，「看看娃娃」會把活動位置移到畫面中央。點選小島標籤或功能卡片開啟日常。可按「展開地圖」使用全視窗探索，按 Escape 收起。

## 開發

需要 Node.js 22 以上（目前以 24.19.0 驗證）。

```sh
npm ci
npm run dev
```

```sh
npm run build     # 產出 dist，可部署至靜態網站主機
npm run preview   # 預覽正式建置
npm test          # 娃娃活動邏輯與 Chromium 功能測試
```

瀏覽器測試預設使用 `/usr/bin/chromium`，可透過 `CHROMIUM_PATH` 指定其他 Chromium 路徑。

## React 與 Three.js 分工

介面已改由 React 管理：應用狀態、導覽、待辦與日曆、記事與留言、回憶照片、居民卡片、問候對話、地圖控制與造型工作室。Three.js 專門管理場景、娃娃模型、活動動畫、相機、拾取與造型預覽；不再建立問候框或編輯器表單。

- `src/main.jsx`：React 入口。
- `src/App.jsx`：頁面與狀態協調、彈窗、資料保存、地圖操作。
- `src/ui/`：React 介面元件，包括 `WorldViewport.jsx`、`Journals.jsx`、`FriendsPanel.jsx`、`ResidentEditor.jsx`。
- `src/world.js`：Three.js 主場景執行階段，以方法接收指令、回呼送出事件。
- `src/shape-preview.js`：獨立的 Three.js 造型預覽與相機控制。
- `src/resident-life.js`、`src/resident-shape.js`：活動與造型邏輯，不依賴 React。

場景透過 React effect 建立與銷毀，元件重新渲染不會重建模型；動畫每幀直接更新 Three.js。投影到畫面上的地圖標籤使用專屬 DOM 容器，座標更新由場景控制，React 不覆寫容器內容。原有 localStorage 鍵值與資料格式保留。更詳細的遷移紀錄見 [React／Three.js 分工](docs/react-three-migration.md)。

## 娃娃造型工作室

開啟「家人朋友」，按娃娃卡片上的「調整造型」；或點擊地圖上的娃娃，再按問候框中的「調整造型」。六位居民都可選擇，用滑桿即時調整整體大小、頭部寬高與厚度、肚子胖度、手腳和眼睛位置；恐龍另可調整尾巴。支援拖曳旋轉、縮放，以及正面／側面／背面／斜角預覽，手機也能操作。

按「儲存並套用」後，設定會套用到島上的 3D 娃娃，並儲存在目前瀏覽器的 localStorage（`little-island-shapes-v1`）；重新整理會保留。家人朋友卡片的平面 SVG 插圖不隨 3D 設定變動。可恢復原始造型、還原未儲存調整，以及匯入／匯出 JSON 設定。匯出的檔案包含目前未儲存的預覽，可備份、跨裝置匯入，或提供給開發者套用成網站預設造型；不會自動修改儲存庫或同步到其他訪客。

## 功能

- 待辦：依新增時間由新到舊、點選文字編輯內容／日期／時間、完成／單筆刪除／刪除已完成、預定日期、選填時間、月曆與月份切換。時間未選時保持空白，清單預設顯示近 14 天新增的項目。今天或未來 24 小時有未完成待辦時，島上會升起熱氣球提醒；點擊可查看提醒清單，包含較早建立但現在才到期的項目。未選時間的待辦只在預定當天提醒；當天已過時間但未完成的待辦仍保留提醒。提醒每分鐘及操作後更新，全部完成即收起；不需通知權限。
- 記事：新增標題、內文、作者，並可留言及刪除記事。
- 島嶼佈景：六島採固定種子的自然群落配置，建物錯落分布，搭配疏密不同的樹叢、草地與花叢，不再沿圓周排列；移除地面六角框線、島邊淺色框、數字圓牌與彩色棋路，地表改為柔和的草地、泥土及岩地紋理。各島補上數十棵新樹形成較濃密的樹林，樹幹會擋路但樹冠下仍能通行；步道依實際可走路線連接橋頭與景點，花草增加為多片密集花叢。主島與公園的河流延伸穿過海岸，河口順著高度落入海面，並保留跨河小橋。各島保留主題景點，包含麵包市集、果園、森林露營地、蘑菇小徑、風車麥田、露天書攤、野餐桌、遊戲區、池塘與觀星望遠鏡；橋頭保留通行走廊。海域半徑由 47.3 擴大至 64，外圍接上草原、沙岸與 28 座山丘，縮小地圖可看見完整外圍景觀。新增實體佈景也納入娃娃尋路的碰撞範圍。
- 家人朋友：三隻小熊（包含依照片製作的灰色藍橘花紋「熊熊」）、一隻兔兔與依照片製作的薄荷綠青蛙「呱呱」、粉紅色「恐龍」會隨機分散在六座不同島嶼的安全位置，各自散步、跨島探索與看風景；偶爾才安排一對居民在某座島上結伴散步或玩球，或去公園盪鞦韆、坐在長椅上聊天，其餘居民繼續自己的活動。房屋、樹木、山丘、圍欄、長椅與桌遊佈景都有碰撞範圍，角色會先規劃繞行路線並逐步檢查；河流只能走小橋通過。島嶼的寬度與深度再擴大兩倍，橋面寬度也加倍；寬橋可並行及雙向交錯通行。角色會預測未來三秒的碰撞，雙方持續靠自己的右側繞過後繼續原本路線；空間不足時按固定優先順序等待或退讓，持續卡住三秒才重新規劃路線。卡住時的備援仍記住最近十次嘗試方向，不重複這十次內的方向；活動切換也維持安全間隔。每次重新載入會重新分配島嶼與安全起點，停留時會輪換獨處和兩人相聚的活動；「看看娃娃」可拉近視角。點擊地圖上的娃娃、居民插圖或「打個招呼」，娃娃會暫停活動並顯示問候；可拖曳從不同角度觀察，按「繼續去玩吧」、收起地圖或 Escape 後恢復活動。居民設定位於 `src/household.js` 的初始資料。恐龍依正面與四個斜角的照片建模，保留白色下巴與肚皮、紫色背鰭和尾巴，省略鑰匙鏈、吊環與標籤。
- 回憶：上傳照片、標題、日期與文字，可放大或刪除。照片在瀏覽器縮圖壓縮後儲存。
- 環境音、重設視角、手機版、鍵盤操作與減少動態效果偏好。

## 資料保存範圍

本版本是前端原型，使用目前瀏覽器的 localStorage（`little-island-v1`），沒有帳號、伺服器或跨裝置同步。清除網站資料會刪除內容。照片共享、多人使用與正式備份需接上資料庫、檔案儲存與登入權限。初次開啟提供三件示範待辦與一則示範記事；照片回憶從空白開始。

網站使用 Google Fonts，無法連線時會使用系統字型。島嶼、建築、植物與娃娃均由程式建立，不依賴外部模型。參考網址在開發環境受網路規則限制，作品依使用者描述自行設計。

## GitHub Pages 發布

原始碼保存在 `main`，後續直接在 `main` 開發，不需為每次修改建立分支。`gh-pages` 分支僅存放正式建置檔，用於發布網站。

第一次啟用：在 GitHub 儲存庫的 **Settings → Pages**，選擇 **Deploy from a branch**，分支選 **gh-pages**、目錄選 **/ (root)**，再儲存。預期網址為 `https://skylinkeming.github.io/my-fairy-land/`；是否已上線應以 GitHub Pages 的部署結果為準。

後續每次修改完成並驗證後，直接將原始碼提交至 `main`，並把 `dist/` 內容發布至 `gh-pages`，不需另行確認。發布前執行 `npm ci`、`npm test`、`npm run build`；若檢查失敗，應如實回報。發布時保留 `.nojekyll`。不要把原始 `index.html` 直接當作正式部署檔；它需要開發伺服器，正式檔位於 `dist/`。

若裝置不支援 WebGL、GPU 連線中斷或 3D 模組下載失敗，網站會改用可點選的插畫地圖。主程式無法下載時會顯示可讀取的重新載入畫面。
